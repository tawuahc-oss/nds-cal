# 管理員操作

## 日常活動

1. 開啟月曆，按「管理員登入」。
2. 選日期後按「新增活動」，或在後台按「新增活動」。
3. 在同一張表格填寫名稱、日期時間、地點、分類、描述及備註。
4. 需要重複時選每日／每週／每月／每年。每月第一個星期一請選：
   每月 → 每月第幾個星期幾 → 第一個 → 星期一。
5. 開始日必須符合規則，例如 2026-11-02；不是任意挑一日。
6. 儲存後本頁立即更新；其他已開啟的月曆每分鐘更新，亦可手動重新整理。

## 編輯與取消

點月曆活動可看詳情。重複活動可「只修改這一次」或「修改整個系列」。
後台的「單次活動／恢復」會列出目前月份的活動，包括已取消的聚會。
恢復會移除該次例外，重新採用原定系列內容。
已有單次例外的系列，不能直接更改重複時間表；請先恢復例外。
第五個星期幾不存在的月份會跳過，不會移到下月。

## 年度封存與約兩年保留

目前需求以年度報告為主，未啟用每日／每週自動備份排程。

1. 每年完成上一年度的內容檢查。
2. 在「年度封存／兩年保留」選封存年份。
3. 分別下載年度月曆 PDF、年度詳細 PDF、完整還原 JSON。
4. 打開兩份 PDF 確認繁體中文、活動內容和頁數；把 JSON 一併保存在安全位置。
5. 可把這三份檔案自行存到 Google Drive 的 NDS Calendar Backups。
6. 預設保留「今年＋去年」；未來活動不會清理。
7. 清理前先按「只預覽，不刪除」。網頁只提供預覽。正式清理前，須核對兩份 PDF、在副本還原 JSON，並核對清理清單。

沒有排程會自動刪除資料。仍在重複、沒有明確結束日期、僅按次數結束、
或包含單次例外的系列會受到保護，需另行檢查。系列起始日期即使較舊，
也可能是正確計算未來重複所必需，不能直接截短或刪除。
詳細 PDF 及完整 JSON 不受畫面分類篩選影響，避免誤漏資料。
PDF 供閱讀，JSON／SQL 供還原；PDF 本身不能完整還原系統。

## 登入安全

登入 token 保存在目前分頁的 sessionStorage；同一分頁刷新不需重登，
到期／登出／關閉分頁會清除。請在共用電腦完成操作後登出。
任何 XSS 都可能讀取這種 token，因此保留 CSP、使用純文字呈現使用者內容，
不要加入不明的第三方腳本。個別瀏覽器的「重新開啟已關閉分頁」可能恢復工作階段；
登出才是撤銷伺服器憑證的可靠方法。

「帳戶安全」可更改密碼，會登出全部管理員並作廢舊復原碼。
登入後可重新產生一次性復原碼，檔案應離線保管，不能放到 GitHub。
若沒有復原碼且忘記密碼，須由 Cloudflare 帳戶管理者在維護時段重設，
網站沒有公開的免驗證重設入口。
密碼接受 6–128 字元並拒絕部分常見值；建議獨特、至少 12 字元的密語。
共用帳戶無法識別實際操作的同工；稽核記錄不能當作個人身分證明。
曾曝光的正式密碼仍須由你主動更換，本次開發不會代你更換。
